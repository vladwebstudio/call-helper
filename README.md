# Помічник розмови (суфлер для дзвінків)

Слухає розмову через мікрофон телефону, кожні 5 с розпізнає мову і показує картки: **біль / заперечення / сумнів / сигнал** + по 3 питання під кожною. Без ШІ: рушій правил у `public/patterns.js`. Без бази і PIN. «Завершити» повністю очищає стан.

## Запуск (Mac)
1. Двічі клікни `start.command` (запускає локальний whisper і сервер).
2. На комп'ютері: `http://localhost:8080`. На телефоні (та сама Wi-Fi): адреса `https://IP:8443` з вікна терміналу, прийняти попередження про сертифікат.
3. «Новий клієнт» → говорити. «Подивитись демо» працює без мікрофона.

## Додати біль/заперечення
Відкрий `public/patterns.js`, скопіюй будь-який блок у `ITEMS`: `id`, `kind`, `title`, `pats` (варіанти слів), `neg` (виключення), `q` (3 питання). Перевірка: `node claude/tests/engine-test.mjs файл.txt`.

## Розпізнавання
`STT_PROVIDER` у `.env`: `local` (whisper.cpp), `groq`, `custom` (свій сервер). Ключі тільки в `.env`, він у `.gitignore`.
